# Wrela

Wrela is a programming language for building complete bootable Images rather than applications hosted by a conventional operating system; its flagship Image is a field-rendered game Console.

## Language

**Console**:
A curated kind of Image for field-rendered games and the flagship Wrela product.
_Avoid_: Every Wrela artifact, generic runtime

**Image**:
A self-contained bootable artifact containing all system software, selected device support, immutable content, and behavior needed for one closed Wrela system.
_Avoid_: Console Image, executable, program, application bundle

**Project**:
A manifest-free source tree whose only root source is `src/image.wr`, with one reachable Image Constructor and no external dependencies; every other Module is hierarchically nested and derives identity from its conventional Project-relative path.
_Avoid_: Package, crate, dependency graph

**Module**:
A single hierarchical `.wr` source file whose identity derives from its canonical path beneath a Project's `src/` directory or from an authenticated Compiler Distribution registry; one `from parent import leaf [as alias]` form imports its complete namespace, through which its `pub` declarations are accessed.
_Avoid_: Package, path declaration, implicit global namespace

**Image Constructor**:
The single `@image` function evaluated as effect-free ordinary Wrela during the build to select Image Facilities, declare bounded resources, create Actors, and return the closed Image graph.
_Avoid_: Configuration file, macro language, runtime entry point

**Build Constructor**:
A sealed pure operation available during Image construction that creates one typed symbolic declaration for the returned Image graph without performing a runtime or ambient host effect.
_Avoid_: Compiler Primitive, Facility planner, mutable compiler callback

**Image Facility**:
A high-level Image declaration such as Input, Display, or Event Store that expands into its sealed Drivers, Actors, Pools, interrupts, and Device Manifest entries.
_Avoid_: Raw transport, manually assembled kernel service, host plugin

**VM ABI**:
The versioned interface jointly implemented by an Image and its virtual machine monitor, covering boot, memory handoff, device enumeration, interrupt delivery, Panic, and shutdown.
_Avoid_: Machine, Platform, Target

**Architecture Profile**:
The compiler-known native-code selection of ISA, CPU-feature baseline, calling convention, backend settings, and trusted architecture stubs used to build one Image.
_Avoid_: Target Profile, Machine, Platform

**Boot Contract**:
The sealed architecture-independent entry state that every primary and secondary core receives after its Architecture Profile has normalized reset and startup mechanics.
_Avoid_: Raw reset registers, boot Actor, firmware protocol

**Device Manifest**:
A build-produced declaration of the Virtio devices and VM ABI resources required by one Image.
_Avoid_: Hardware profile, device discovery

**Driver**:
A safe guest implementation of a supported Virtio device contract that may be selected into an Image.
_Avoid_: Device model, host adapter

**Space**:
A compiler-known topology and coordinate domain in which Forms, Regions, and spatial mappings are defined.
_Avoid_: Untyped coordinate convention, raw vector domain

**Form**:
A compile-time symbolic description of a continuous spatial subject in a Space, classified by a kind such as Solid, Surface, Medium, Pattern, or Region.
_Avoid_: Mesh, scene node, arbitrary sample function

**World**:
A statically admitted arrangement of Form families that may be finite or deterministically generated by bounded regions. A World is presentation structure and never owns authoritative game state.
_Avoid_: Scene graph, mutable game world, draw list

**View**:
A pure presentation that maps a bounded read-only game snapshot into one or more Worlds and Screen-space Forms.
_Avoid_: Camera Actor, mutable renderer state, draw callback

**Material**:
An analyzable description of a Form's local appearance and response to incoming light in explicitly typed coordinates.
_Avoid_: Texture, shader program, arbitrary per-pixel callback

**Transport**:
A bounded analyzable description of how light reaches Materials, including direct light, shadows, finite secondary queries, reconstruction, and deterministic reuse.
_Avoid_: Arbitrary recursive integrator, baked lighting

**Field**:
The compiler-owned continuous spatial representation derived from Forms for evaluation and optimization; Creators do not author raw Fields as the normal visual interface.
_Avoid_: Creator-facing signed-distance function, mesh, texture

**Display**:
The Image Facility that accepts presentation snapshots for compiled Views, executes their deterministic CPU plans, retains disposable caches and complete frame buffers, and submits frames to Scanout.
_Avoid_: Pixels, authoritative visual state, GPU renderer

**Scanout**:
The fixed-resolution display surface that receives complete CPU-rendered frames from Display through the unaccelerated Virtio-GPU 2D protocol.
_Avoid_: GPU rendering, graphics acceleration

**Body**:
Explicit gameplay geometry used for collision, navigation, targeting, or other authoritative spatial rules independently of a subject's visual Form.
_Avoid_: Rendered silhouette, automatic visual collision

**Mark**:
An Image-wide identity that lets a gameplay subject remain recognizable across Worlds and Views; local part labels identify its visual components without creating global identities for each part.
_Avoid_: Scene-node address, globally eternal identifier

**Visual Contract**:
The checked Console obligations governing semantic preservation, visible error, temporal age, and permitted simplification for a presentation subject.
_Avoid_: Quality hint, frame-time heuristic

**Reference Console**:
The concrete minimum supported host and VM configuration against which Display cost models and performance gates are calibrated.
_Avoid_: Current development machine, abstract ISA budget

**Creator**:
A curious solo programmer who builds Images and, when desired, works on the underlying Wrela system software.
_Avoid_: App developer, kernel expert

**Authoring Parameter**:
A Creator-declared source value with sufficient semantic identity and provenance for a graphical editor to inspect and manipulate without rewriting the abstraction that produced it.
_Avoid_: Generated visual result, hidden editor override, decompiled constant

**Source Transaction**:
One atomic human- or agent-authored semantic edit represented as an exact Wrela source patch with diagnostics, preview impact, and reversible history.
_Avoid_: UI gesture recording, private scene mutation, invisible agent state

**Semantic Identity**:
The closure-scoped identity of one named semantic thing, preserved across edits that retain its defining Module, owner chain, declaration kind, and name; its current meaning is checked separately through a Semantic Fingerprint.
_Avoid_: Source address, global Project identity, qualified-name string, artifact version

**Semantic Fingerprint**:
A deterministic description of a semantic thing's current meaning used to detect incompatible edits and stale artifacts without pretending the thing itself was deleted and recreated.
_Avoid_: Semantic Identity, source revision, security signature

**Identity Catalog**:
The immutable compiler-owned catalog that interns canonical Semantic Identity keys for one compilation revision and carries their typed opaque IDs, readable names, provenance, and Semantic Fingerprints across compiler phases.
_Avoid_: Symbol table, global registry, mutable compiler session

**Specialization**:
One executable function or method body after every type, compile-time Data, and Pool argument has been fixed for the closed Image.
_Avoid_: Generic instance, Actor instance, runtime object

**Capability**:
An unforgeable value granting narrowly scoped authority over an Image resource or privileged operation.
_Avoid_: Permission flag, raw handle

**Compiler Primitive**:
A sealed, typed operation available only to authenticated Wrela runtime and Driver modules when ordinary safe language operations cannot express the required effect.
_Avoid_: Intrinsic string, unsafe escape hatch, inline assembly

**Evidence Bundle**:
A canonical host-side artifact keyed by Image digest that relates compact Image diagnostic identities to Project-relative source spans, symbols, layouts, plans, and compiler receipts.
_Avoid_: Embedded source archive, text build log, host-path dump

**Data**:
A value that copies implicitly; the build report exposes copies whose cost may matter.
_Avoid_: Plain old data

**Resource**:
A value with one owner that moves only through explicit `take` and must be reclaimed, consumed, or transferred on every recoverable path.
_Avoid_: Object, implicitly moved value

**Untrusted**:
A sealed wrapper around an external control value that cannot influence indexing, allocation, or dispatch until checked into a bounded value.
_Avoid_: General taint, untrusted payload bytes

**Driver Error**:
A recoverable failure produced when a Driver can contain malformed device behavior, restore ownership, and safely quiesce or reset the device.
_Avoid_: Panic, ignored device fault

**Input**:
The Image Facility exposing game-facing keyboard and mouse state. A host controller may later be mapped into configured digital keybindings without becoming a guest-visible device contract.
_Avoid_: Host keycode, evdev device, mandatory gamepad protocol

**Input Sample**:
A bounded typed pull observation containing normalized current controls, accumulated transitions and movement, and focus state, consumed by the one Actor statically wired as an Image's Input owner.
_Avoid_: Broadcast host event, dynamically routed callback, raw device packet, host interrupt order

**Action Map**:
An ordinary standard-library mapping from normalized physical Input controls to one Image's typed semantic actions.
_Avoid_: Host key binding, raw device map, hidden Facility behavior

**Campaign Epoch**:
A persistent flagship progression identity begun by `New` or deliberate `Reset`; projections expose the current epoch without treating reset as host-side Store deletion.
_Avoid_: Event Store replacement, memory reset, erased history

**Preview Fixture**:
An effect-free typed Wrela declaration supplying bounded presentation Data for editor preview without running Actors or Facilities.
_Avoid_: Editor JSON, captured guest memory, hidden mock state

**Preview Kernel**:
A sealed effect-free native fragment lowered from an admitted World or Transport plan for interactive editor preview without gaining host authority or becoming a Wrela deployment target.
_Avoid_: Host application, Actor runtime, gameplay JIT, semantic oracle

**Preview Worker**:
The replaceable host child process that executes sealed Preview Kernels outside the graphical editor's address space.
_Avoid_: Wrela Image, security sandbox, effectful runtime, editor plugin host

**Event Store**:
The Image's lowest-level persistent data abstraction: a single ordered event-sourced database whose immutable events are the source of truth. Virtio-Block is an incidental storage-engine boundary and is not exposed to Creators.
_Avoid_: Save capability, filesystem, raw block device, mutable record store

**Event**:
An immutable persistent record occupying exactly one fixed-width Event Slot, with a typed Creator-defined wire payload inside a canonical Event Store envelope.
_Avoid_: Mutable row, raw disk record, telemetry sample

**Event Slot**:
The fixed-width unit of Event Store capacity. Its width is selected during Greenfield Mode and frozen by the Event Schema Lock; unused payload bytes have one canonical zero representation.
_Avoid_: Variable-length record, disk sector, allocation extent

**Wire Layout**:
A compiler-checked exact byte representation used by Event payloads and Store Snapshots. It has explicit endianness, offsets, and padding, and canonically encodes fixed-width integers, strict booleans, IEEE-754 floats, fixed arrays, and nested Wire Layouts.
_Avoid_: Native struct layout, serializer option, implicit padding

**Logical Image Layout**:
The target-neutral bounded arrangement of an Image's Pools, Mailboxes, frames, buffers, Facility state, scheduler structures, and memory regions.
_Avoid_: Native struct layout, linker address map, Wire Layout

**Target ABI Layout**:
The target-specific calling, alignment, relocation, stack, register, and machine representation used after Logical Image planning.
_Avoid_: Wire Layout, Event schema, generic Image capacity plan

**Event Transaction**:
One Creator-declared ordered batch of Events that becomes visible and durable atomically. It is identified by a fixed producer and monotonic producer sequence. The Event Store may group several transactions into one physical flush without merging their logical boundaries.
_Avoid_: Database session, isolation level, individual block write

**Event Producer**:
A build-known Actor allowed to submit Event Transactions, identified independently of its source name and limited to one unacknowledged transaction at a time.
_Avoid_: Concurrent database client, arbitrary primary key, block writer

**Projection**:
A pure bounded fold that derives typed in-memory state by applying every committed Event sequence exactly once and cannot perform effects during recovery.
_Avoid_: Persistent table, ad hoc query, effectful event handler

**Store Snapshot**:
An authoritative, schema-locked Wire Layout representing the root projected state at one committed sequence; it becomes the starting state after the preceding Event prefix is reclaimed.
_Avoid_: Disposable cache, memory dump, individual Event

**Store Identity**:
The stable production identity that lets compatible releases of one game open the same Event Store independently of their Image digests.
_Avoid_: Image digest, project path, host filename

**Event Schema Lock**:
A repository-persisted production contract recording released Event payload schemas and the compatible upcast paths required when they evolve.
_Avoid_: Dependency lockfile, runtime schema registry

**Greenfield Mode**:
The Event schema lifecycle used before production compatibility matters, allowing schema changes without preserving old Event Store data.
_Avoid_: Production migration, compatibility promise

**Production Mode**:
The Event schema lifecycle governed by an Event Schema Lock, in which every released payload remains readable through a safe upcast path.
_Avoid_: Unversioned schema change, automatic data loss

**Replay**:
A host-managed deterministic artifact containing admitted Input Samples, explicit gameplay seeds, and logical boundaries used to reproduce a run independently from persistent game truth.
_Avoid_: Event Store, telemetry, wall-clock recording

**Telemetry**:
Loss-tolerant operational observations written to a bounded memory ring and drained by the host without delaying gameplay.
_Avoid_: Event, Replay, durable game state

**Monotonic Clock**:
The Image's architecture-independent elapsed-time source; deterministic state and Replay advance through recorded logical boundaries such as Cadence occurrences rather than host wall time.
_Avoid_: Wall clock, calendar clock

**Cadence**:
An ordinary standard-library Wrela module that turns bounded Monotonic Clock wakeups into exactly-once numbered recurring messages for statically wired Actors, with at most one occurrence outstanding.
_Avoid_: Image Update, Console intrinsic, timer Facility

**Entropy**:
Nondeterministic random input reserved for facilities outside replayable gameplay; gameplay randomness begins from an explicit recorded seed.
_Avoid_: Game PRNG, implicit random seed

**Pool**:
A bounded allocation store with either Image lifetime or a scoped lifetime whose contents are reclaimed together.
_Avoid_: Region, arena, heap

**Pool Permit**:
A one-shot Resource reserving capacity for a future infallible allocation from one Pool.
_Avoid_: Memory pointer, optional capacity hint

**Actor**:
The Image-lifetime owner of mutable state and the unit that receives bounded messages through an explicitly Image-wired handle. Initial Wrela permits only statically named destinations, not runtime collections or selection of Actor handles.
_Avoid_: Object, service thread

**Mailbox**:
An Actor's bounded FIFO admission queue whose ordering derives from logical Image execution rather than host arrival time.
_Avoid_: Host channel, unbounded queue, event loop

**Reply**:
A one-shot Resource moved with a request so its receiving Actor must fulfill or explicitly cancel the waiting result.
_Avoid_: Shared future, callback Actor, copyable promise

**Turn**:
One Actor's exclusive handling of an admitted message from entry through completion or Panic; suspension lets other Actors run but does not admit a second Turn into the same Actor.
_Avoid_: Thread, callback

**Group**:
A bounded structured-concurrency scope that owns child activations, an optional deadline, cancellation, and the cleanup that must finish before cancellation becomes observable outside the Group.
_Avoid_: Detached task, request context, nursery

**Panic**:
An uncatchable runtime defect that records a bounded diagnostic and ends an Image through the VM ABI without running source-level cleanup.
_Avoid_: Exception, recoverable error, abandonment

**Shutdown**:
The structured recoverable protocol by which one Image-wired owner quiesces Facilities, completes root cleanup, and ends the Image with a typed reason.
_Avoid_: Panic, Actor return, host kill

**Image Result**:
The typed VM ABI outcome distinguishing normal completion, requested Shutdown, Boot Failure, Shutdown Failure, Panic, and observable host power loss.
_Avoid_: Process exit code, parsed log message
