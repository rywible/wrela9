Cases that decide the model

Validated decision

One verified transition authority, several purpose-owned projections

  • Semantic authority: one immutable Flow obligation/event graph models messages, logical admission commits, Turn leases, Suspension Homes, Replies, Groups, cleanup, deadlines, and Panic. Runtime tables and scheduler actions are derived projections.
  • Deterministic admission: each proposal carries stable destination, sender Actor, sender Turn sequence, and send ordinal. A scheduled ingress arbitration orders the eligible set canonically; host arrival never breaks ties or adds capacity.
  • Custody boundary: before Mailbox Transfer Commit, a waiting proposal owns moved arguments and returns them on Full or pre-admission cancellation. After commit, cancellation of the sender cannot retract the message.
  • Non-reentrant Turns: an Actor holds one Turn lease from message acceptance through completion or Panic. Suspension moves live state into a static Suspension Home but retains that lease.
  • Replies: request admission reserves the one-shot return path and response storage. Fulfillment cannot fail for capacity; a closed waiter produces ReplyClosed with undelivered ownership. Reply-wait cycles held across Turns are rejected.
  • Structured cancellation: a Group closes admission, quiesces children at bounded checkpoints, returns moved Resources, and runs Cleanup Actions in reverse logical registration order before cancellation becomes observable. Panic runs none of that cleanup.
  • Planning Requirements: Flow exports provenance-bearing bounds for Mailbox commitment, proposal transport, return paths, response storage, static frames, Group activations, cleanup homes, fixed placement, service delay, cancellation latency, deadline class, and deterministic ordering. ImagePlan remains final admission authority.
