        Cases that decide the model

        Validated decision

        One commitment invariant, typed Permits, no generation wrap

        • Capacity is a logical allocation count: live allocations + outstanding Permits ≤ usable slots ≤ declared capacity.
        • try_allocate commits only on success and returns PoolFull[T] with unchanged custody on failure.
        • allocate and reserve[P,T] require Admission Evidence. A typed one-shot Permit reserves one exact future allocation; consuming it changes reserved custody into live custody without increasing commitment.
        • Key[P,T] is copied Data, never grants custody, and succeeds only when Pool identity, slot, generation, and type all match a live allocation.
        • Reclaim consumes own[P] T, returns T, advances the generation, and never revives a stale Key. Exhausted generations retire rather than wrap.
        • Image planning uses path-sensitive live ranges, reservations, cleanup, cancellation, and concurrent activations—not static allocation-site counting. Proof success never changes source-visible types.
