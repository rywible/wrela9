# Compose Virtio devices behind one VM ABI

Each Image will select the Drivers it needs from Wrela's supported Virtio library, and its Device Manifest will configure the virtual machine monitor to provide exactly those devices. Wrela's pinned QEMU configuration will expose one flat restricted modern Virtio-PCI profile on both architectures: non-transitional devices directly on the root bus, split queues, compiler-assigned BDFs and MMIO from a finite Architecture Profile slot table, a fixed required feature set, INTx initially, and no legacy interface, bridges, hotplug, packed queues, MSI-X, IOMMU, SR-IOV, or general-purpose PCI discovery. Sealed boot still validates and configures each declared function's BARs and bounded modern Virtio capabilities; fixed placement never means assuming raw register offsets. Shared INTx sources are inspected and scheduled in manifest order under bounded service quotas. Wrela will prefer stock Virtio devices and will not patch QEMU to add private devices. Keyboard and mouse are the initial game-input devices; later host-side controller mapping may synthesize their digital bindings without changing the guest interface.
