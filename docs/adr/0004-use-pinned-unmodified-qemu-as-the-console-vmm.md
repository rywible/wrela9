# Use pinned unmodified QEMU as the Console VMM

Wrela will ship a pinned, unmodified QEMU release as the virtual machine monitor that runs Images. A Wrela-owned launcher will enforce the Architecture Profile's exact QEMU identity, versioned machine, CPU and memory configuration, canonical flags, and Device Manifest while hiding QEMU's command-line surface from Creators. The same Image may use a compatible HVF, KVM, or TCG accelerator without changing guest semantics. Wrela will own the VM ABI, firmwareless architecture launch members, guest Drivers, conformance corpus, and launcher, but will neither maintain a QEMU fork nor build a second production VMM. This keeps effort on the language, Images, and the flagship Console's CPU-only World and Display stack while relying on QEMU's mature cross-host virtualization and stock Virtio devices.
