# Use the build evaluator as the pure semantic oracle

The simple evaluator required for constants and effect-free Image construction will define the behavior of pure Wrela operations, and compiled backends must agree with it through a shared conformance corpus. It executes only verified fully concrete Typed HIR through one private deep Module with explicit control, call, and value stacks, deterministic logical fuel, and bounded evaluator memory. Generic templates remain specialization recipes rather than partially executable HIR, and evaluator results remain immutable side tables rather than mutations of semantic bodies. Wrela adds neither an Eval IR nor host-recursive or JIT-defined semantics.

Closed policies validate const Data, Boolean conditions, pure calls, and Image construction without changing language behavior. Eligibility excludes ambient host state and effectful runtime authority; Image construction additionally permits sealed pure Build Constructors that create only the typed symbolic graph returned by the Image Constructor. Facility planners run after generic graph sealing rather than as evaluator callbacks. Every loop and recursive cycle is compiler-proven finite before execution: fixed versioned evaluator limits contain compiler work and never revive Wrela8's trusted `@budget` assertion.

Structured outcomes distinguish completed Wrela values, Creator rejection, Panic, limit exhaustion, cancellation, and compiler Defect. Artifact fingerprints, Identity Catalog ownership, structural verification, canonical work ordering, logical resource receipts, and purpose-owned diagnostic rendering keep private reuse and host scheduling semantically invisible. Wrela will not build a second complete interpreter for Drivers, Actors, or other effectful Image execution; those semantics remain governed by specifications, models, and conformance Images. This supplies an independent oracle for optimized pure code without duplicating the complete runtime or exposing internal phase artifacts as a public compiler Interface.
