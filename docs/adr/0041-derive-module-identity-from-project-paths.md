# Derive Module identity from Project paths

Wrela Projects use one manifest-free conventional topology: `src/image.wr` is the root Module and every `src/**/*.wr` file derives its Module identity directly from its canonical Project-relative path. Source has no redundant Module declaration. Absolute imports bind whole Module namespaces, optionally through `as`, and expose that Module's `pub` declarations without copying names into unqualified scope. The compiler derives an acyclic transitive closure from `image` inside a complete immutable source snapshot, so host discovery remains outside the Compiler Module while unreachable source remains semantically inert. This trades path-independent Module identity and selective imports for substantially less Creator bookkeeping, unambiguous provenance, and one deterministic mapping from source trees to Module graphs.
