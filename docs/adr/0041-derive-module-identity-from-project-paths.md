# Derive Module identity from Project paths

Wrela Projects use one manifest-free conventional topology: `src/image.wr` is the only root-level source and every other Module is nested beneath at least one directory, deriving its identity directly from its canonical Project-relative path. Source has no redundant Module declaration. The one import form, `from parent.path import leaf [as alias]`, binds the complete Module namespace under its leaf or alias and exposes that Module's `pub` declarations only through the namespace; selective declaration imports and alternative whole-path syntax do not exist. The compiler derives an acyclic transitive closure from the non-importable `image` root inside a complete immutable source snapshot, so host discovery remains outside the Compiler Module while unreachable valid source remains semantically inert. This trades path-independent identity, root-level utility Modules, and selective imports for a useful hierarchy, less import bookkeeping, unambiguous provenance, and one deterministic mapping from source trees to Module graphs.
