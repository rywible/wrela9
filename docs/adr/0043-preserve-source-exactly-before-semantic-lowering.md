# Preserve source exactly before semantic lowering

Wrela will parse every source file into an immutable lossless syntax tree before semantic lowering. Every input byte belongs to exactly one token, trivia region, or invalid-token node, and printing an unedited tree reproduces the original bytes exactly. Recovery may add distinguishable zero-width missing nodes but never invented source bytes. Structurally valid declaration islands may lower independently for diagnostics, while malformed declarations and all syntax recovery artifacts remain syntax-only; no error node or placeholder type crosses the semantic boundary. This trades a smaller fail-fast parser for exact Creator source preservation, reliable Source Transactions, useful rejected-build inspection, and one clean boundary between authored text and compiler meaning.
