# Synthesize standard Data capabilities

Wrela will automatically synthesize its standard `Eq`, `Order`, and `Hash` capabilities for every Data struct and enum whose components support the corresponding capability. Their meanings are fixed: structural equality, declaration-order lexicographic ordering, and structural hashing consistent with equality. Creator source does not request derivation, and initially cannot override these meanings; custom domain behavior uses a named wrapper or key projection. Resource types and types containing components without the relevant total contract, including ordinary floats, do not receive that capability. This removes derivation bookkeeping while preventing a type from quietly presenting domain-specific behavior as Wrela's standard structural contract.
