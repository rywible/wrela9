# Make one fast Check the sole release authority

Wrela will keep one deterministic command, Check, as the sole technical authority for merge and release. A Passed Check makes the exact revision Releasable by establishing every currently encoded Release Obligation; there are no separate edit, full, CI, or release tiers. Representative warm execution targets less than one second and has a two-second ceiling on the Reference Development Host, forcing new evidence to use narrow Regression Cases, structured observations, deterministic models, work bounds, verifiers, and one tiny real QEMU boot rather than accumulating slow end-to-end suites. This trades the apparent breadth of a per-release qualification ceremony for a development loop that is cheap enough to run after every change and whose authority cannot become ambiguous.

Named Challenges attack the assumptions and omissions in Check but never contribute release status. Each Challenge answers a stated investigative question, terminates within one minute, shares a one-minute aggregate ordinary-work budget, and never runs automatically or as a suite. A reproducible Challenge Finding must be minimized into Check before the next merge or release. This refines ADR-0030's model and structured-observation strategy: representative Images, broad workflows, fuzzing, and physical performance remain discovery instruments, while their durable semantic value is carried by fast deterministic evidence.
