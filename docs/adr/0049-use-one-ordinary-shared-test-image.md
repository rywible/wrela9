# Use one ordinary shared Test Image

Wrela will compile each `src/test.wr` root into one ordinary Test Image whose sole Image Constructor builds one shared graph and registers an explicit source-ordered list of Wrela Test Applications. Suites own nested Tests for organization and identity but create no runtime value, parameters, fixture scope, or isolation. A Test Application binds ordinary Image values using normal Wrela ownership modes and records a later statically dispatched invocation. Tests execute serially in registration order; sharing mutable authority is legal and observable, failed expectations do not roll state back, and Panic ends the complete Image.

This deliberately gives up automatic case isolation, compiler-controlled reordering, storage overlay, and parallel execution so production and testing retain one Actor, ownership, Facility-cardinality, graph, and lifetime model. Creators construct distinct ordinary state when they need it; Tests over a singleton Facility form an ordered scenario or use another Test Project/Image when a fresh complete lifetime is essential. Check retains one Test Image build, one QEMU boot, and one complete typed report. This supersedes ADR-0047 and deletes the Test Case Graph abstraction rather than renaming its special reachability rules.
