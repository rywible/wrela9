# Own the lossless byte parser

Wrela's authoritative syntax Implementation will be a private standard-library-only Rust subtree containing a handwritten lexer over exact bytes, a separate physical-layout pass, a handwritten event parser, and a small immutable Wrela-owned green tree paired with `Arc<[u8]>` source storage. Physical leaves retain kinds and checked lengths, partition every byte exactly once, and include trivia and invalid encoding; layout and recovery elements are distinguishable and zero-width. The parser uses bounded lookahead, monotonic recovery, checked `u64` ranges, measured source and nesting admission limits, and cooperative cancellation without publishing partial artifacts.

The syntax subtree forbids unsafe code, parser libraries, procedural macros, regex engines, generated parsers, build scripts, and native code. This is a narrow decision rather than a compiler-wide dependency ban: focused Rust dependencies such as Cranelift remain appropriate when their exact features and transitive build, unsafe, native, maintenance, and licensing surfaces are reviewed, their types remain private, and the workspace lockfile is committed.

Source Transactions initially patch immutable bytes and invoke the same complete batch compiler operation as every host. The first tree has no global interning, persistent cache, or incremental parser. Incremental reuse requires production-shaped evidence that full parsing threatens the accepted latency contracts, exact equivalence with fresh parsing after every edit, and a bounded full-parse fallback. Optional fuzz tooling remains a sub-minute Challenge; reproducible Findings become deterministic Regression Cases protecting the byte partition, exact round trip, recovery, progress, semantic boundary, and determinism.

This choice follows the primary-source comparison in `docs/research/lossless-parser-stack.md`. Rowan and cstree have useful immutable-tree designs but store token text as UTF-8 strings; Tree-sitter brings strong incrementality but different source/trivia ownership and recovery semantics plus generated C and an external layout scanner; general lexer and parser frameworks leave Wrela owning the difficult byte, layout, recovery, and tree behavior anyway. Wrela8 remains behavioral provenance for selected grammar, indentation, depth, documentation, golden, and fuzz cases, but its UTF-8-only, trivia-discarding, fail-fast semantic AST and canonical printer are not ported.
